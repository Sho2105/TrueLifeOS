# 1 PHONOLOGY: The Sound Units

## 1.1 Sound System

### 1.1.1 IPA & Alphabet

- 26 graphemes → 44 phonemes. Many-to-one bidirectional. English spelling encodes history, not current sound.

| System | Function | Mapping |
|---|---|---|
| Alphabet | Writing | 1 letter → many sounds |
| IPA | Speech | 1 sound → many spellings |

### 1.1.2 Vowel Phonemes

- 20 vowels: 12 monophthongs + 8 diphthongs. 1 vowel nucleus = 1 syllable.

| Height | Monophthongs | Diphthongs |  |  |
|---|---|---|---|---|
| Long / Example | Short / Example | Sound / Example | Sound / Example |  |
| Close front | /iː/ see | /ɪ/ sit | /eɪ/ day | /aɪ/ sky |
| Close back | /uː/ food | /ʊ/ good | /ɔɪ/ boy | /əʊ/ go |
| Mid-central | /ɜː/ bird | /ə/ about | /ɪə/ near | /eə/ hair |

- 24 consonants: 8 voiced-voiceless pairs + 8 singles.

## 1.2 Syllable Structure

### 1.2.1 Components

- Syllable = onset + nucleus + coda. Nucleus obligatory.

| Part | Definition | Example: plan |
|---|---|---|
| Onset | Initial consonant(s) | /pl/ |
| Nucleus | Core vowel | /æ/ |
| Coda | Final consonant(s) | /n/ |
| Rime | Nucleus + coda | /æn/ |

- 1 nucleus = 1 syllable: string(1); tea-cher(2); beau-ti-ful(3).

## 1.3 Connected Speech Processes

| Process | Definition / Example |
|---|---|
| Assimilation | Sound becomes like neighbour — Progressive(regressive influence forward) | Regressive(active sound influenced by following) | Coalescent(two sounds merge into one). |
| Elision | Omission of sound — next day /nekst deɪ/ → /neks deɪ/; handbag /hændbæg/ → /hæmbæg/. |
| Linking R | Intrusive /r/ between vowels across word boundaries — law(r)and order; media(r)event. |
| Liaison | Linking of final consonant to initial vowel — an apple /ə næpl/; pick it up /pɪ kɪ tʌp/. |
| Gemination | Doubling of identical consonant across boundary — bus stop /bʌs stɒp/ → prolonged /s/. |
| Weak forms | Unstressed function words reduce vowel to schwa — /kən/ for can; /ðə/ for the before consonant. |
| Strong forms | Function words retain full vowel when stressed or isolated — /kæn/; /ðiː/. |
| Schwa /ə/ | Most common vowel in English; appears in unstressed syllables — about, sofa, system. |

## 1.4 Prosody

### 1.4.1 Word Stress

| Pattern | Rule / Example |
|---|---|
| Noun/Verb pairs | Noun: primary stress initial; Verb: primary stress final — RE-cord / re-CORD. |
| Compound nouns | Stress first element — BLACK-board, GREEN-house. |
| Phrasal verbs | Stress particle — give UP, turn OFF. |
| Primary stress | Strongest syllable in word — pho-TO-graph. |
| Secondary stress | Weaker stressed syllable — pho-to-GRA-phic. |
| Unstressed | Reduced to schwa or /ɪ/. |

### 1.4.2 Sentence Stress & Rhythm

- Content words (Noun, Verb, Adjective, Adverb) stressed; function words (article, Preposition, Pronoun) unstressed.
- Intonation: ↓ = statement/command; ↑ = question/uncertainty.

### 1.4.3 Intonation Contours

| Contour | Use / Example |
|---|---|
| Falling ↓ | Statements, wh-questions, commands — Where is it? ↓ |
| Rising ↑ | Yes/no questions, lists, uncertainty — Are you coming? ↑ |
| Fall-Rise ↓↑ | Implication, reservation, contrast — I like it ↓↑ (but...). |
| Rise-Fall ↑↓ | Surprise, strong agreement — Really? ↑↓ |
| Level → | Routine, bored, unfinished — Reading a list. |

- Tone units / Intonation phrases: breath group carrying one contour.

# 2 ORTHOGRAPHY: The Writing Units

## 2.1 The Alphabet

- 26 letters: 5 vowels (a, e, i, o, u), 21 consonants. Upper case & Lower case forms.

## 2.2 Graphemes

| Type | Definition / Example |
|---|---|
| Single-letter | 1 letter = 1 sound — b=/b/, a=/æ/. |
| Digraph | 2 letters = 1 sound — sh=/ʃ/, ch=/tʃ/, th=/θ/ or /ð/, ph=/f/, wh=/w/ or /h/, gh=/f/ or silent, ck=/k/, qu=/kw/. |
| Trigraph | 3 letters = 1 sound — tch=/tʃ/, dge=/dʒ/, igh=/aɪ/. |
| Silent letters | kn=/n/(know), wr=/r/(write), gn=/n/(gnaw), mb=/m/(lamb), l in walk, gh silent(though), b in debt, p in receipt, t in castle, w in write. |

## 2.3 Spelling Conventions

| Rule | Mechanism / Example |
|---|---|
| Magic E | Vowel + Consonant + e → long vowel: bit → bite. |
| C softening | c → /s/ before e,i,y (city); /k/ elsewhere (cat). |
| G softening | g → /dʒ/ before e,i,y (age); /g/ elsewhere (go). |
| Double Consonant | Consonant-Vowel-Consonant + vowel suffix → double final consonant: stop → stopping. |
| Drop silent E | Remove e before vowel suffix: make → making. |
| Y → I | Consonant + y + suffix: happy → happier. |
| I before E | Except after C or when sounding like A: believe, receive, neighbour, weigh. |
| Final -l | Double before suffixes in British English: travelled, cancelled. |

## 2.4 Inflectional Endings

| Ending | Environment | Sound / Example |
|---|---|---|
| -s / -es | /s z ʃ ʒ tʃ dʒ/ | /ɪz/ — kisses, boxes, ... |
| Voiceless /p t k f θ/ | /s/ — stops, cats, ... |  |
| Elsewhere (voiced) | /z/ — dogs, plays, ... |  |
| -ed | /t d/ | /ɪd/ — wanted, decided, ... |
| Voiceless /p k f s ʃ tʃ/ | /t/ — stopped, washed, ... |  |
| Elsewhere (voiced) | /d/ — played, learned, ... |  |

## 2.5 Capitalization Rules

| Context | Rule / Example |
|---|---|
| Sentence | First word always — She left. |
| Proper noun | Names of people, places, institutions, languages, nationalities — London, NASA, English, Vietnamese. |
| I | First person Pronoun always — I am here. |
| Titles | First, last, major words — The Catcher in the Rye; Doctor Smith. |
| Days/Months/Holidays | Always; seasons do not — Monday, July, Christmas; summer. |
| Brand names & Acronyms | NASA, BMW, Kleenex. |
| Personification | Nature smiled. |
| Direct quotation | First word of quoted sentence — He said, "Leave now." |
| Salutations/Closings | Dear Sir, Yours faithfully. |

# 3 MORPHOLOGY: The Word-Building Units

## 3.1 Morpheme Types

| Type | Definition / Example |
|---|---|
| Free | Can stand alone — book, run. |
| Bound | Must attach to another — un-, -ness, -ed. |
| Lexical | Carries core meaning — struct, spect. |
| Grammatical | Carries function — plural -s, past -ed. |
| Root | Core semantic unit — struct→structure, construct. |
| Base | Form to which affix attaches — help→helpful. |
| Stem | Base plus any affixes — helpfulness ← helpful + ness. |

## 3.2 Affixes

### 3.2.1 Prefixes

- Meaning change; class rarely changes. Position: Prefix + Base.

| Category | Prefixes |
|---|---|
| Negation/Reversal | un-, re-, pre-, mis-, dis-, de-. |
| Degree/Size | over-, under-, out-, hyper-, hypo-, mega-, mini-, mid-, micro-, macro-, super-, ultra-, extra-, semi-, sub-, vice-. |
| Number | bi-, mono-, multi-, poly-, tri-, uni-. |
| Time/Order | fore-, post-, pre-, neo-, retro-, ex-. |
| Location/Direction | in-, inter-, intra-, extra-, trans-, tele-. |
| Attitude | anti-, auto-, co-, counter-, pro-, with-. |
| Assimilation variants | il-/im-/in-/ir- before certain consonants — illegal, impossible, intolerant, irregular. |

### 3.2.2 Suffixes

| Class | Suffixes |
|---|---|
| Noun-forming | -ness, -ity, -ty, -er, -or, -ar, -ist, -ian, -ment, -tion, -sion, -ure, -age, -al, -ance, -ence, -dom, -ee, -ess, -hood, -ing, -ism, -ship, -th, -y. |
| Verb-forming | -ize, -ise, -ify, -en, -ate. |
| Adjective-forming | -ful, -less, -ous, -ive, -able, -ible, -al, -ial, -ic, -ical, -ish, -like, -ly, -some, -worthy, -en, -an, -ar, -ary, -ate, -ed, -ern, -escent, -free, -most. |
| Adverb-forming | -ly, -ward, -wards, -wise, -fold, -long, -wide. |
| Inflectional | -s/-es, -'s, -ed, -ing, -er, -est, -en. |

## 3.3 Inflectional Categories

| Category | Distinctions |
|---|---|
| Number | Singular, Plural. |
| Person | First, Second, Third. |
| Tense | Present, Past. |
| Aspect | Progressive, Perfect. |
| Case | Common, Genitive/Possessive. |
| Degree | Positive, Comparative, Superlative. |

## 3.4 Word Formation Processes

| Process | Function / Example |
|---|---|
| Compounding | Combined words — bus stop, toothbrush, mother-in-law, passer-by. Types: Endocentric(head inside), Exocentric(head outside: redhead), Copulative(deaf-mute), Appositional(actor-director); Forms: Closed, Hyphenated, Open. |
| Blending | Parts merged — brunch, smog, motel. |
| Clipping | Shortened form — ad, phone, exam, lab. |
| Acronyms / Initialisms | Initial letters — NATO(pronounced), FBI(spelled), laser(back-formed acronym). |
| Back-formation | Remove supposed affix — edit from editor, babysit from babysitter. |
| Conversion / Zero-derivation | Class shift without affix — bottle(Noun→Verb), empty(Adjective→Verb), up(Adverb→Verb). |
| Eponyms | From proper name — sandwich, boycott, watt. |
| Reduplication | Repeat or near-repeat — goody-goody, so-so. |
| Loanwords / Calques | Borrowed from another language — café(loanword); superman(calque). |

# 4 WORD CLASSES: The Lexical & Grammatical Categories

## 4.1 Nouns

### 4.1.1 Classification

- Noun = person|place|thing|idea. Function: Subject|Object|Complement. Position: [Noun]=Subject/Object/Complement; [Noun]'s=possessive; Determiner Adjective [Noun].

| Type | Nature / Example |
|---|---|
| Common | General — city, book, teacher, ... |
| Proper | Specific — Vietnam, Monday, John, ... |
| Concrete | Tangible — table, water, stone, ... |
| Abstract | Intangible — love, freedom, advice, ... |
| Countable | singular/plural — book, dog, idea, ... |
| Uncountable | No direct plural — water, advice, furniture, ... |
| Collective | Group — team, family, police, ... |
| Compound | Two+ bases — toothbrush, bus stop. |
| Gerund | Verb-ing as Noun — Swimming is good. |
| Verbal noun | Derived from verb — destruction(arrive→arrival). |
| Agent noun | Performer — teacher, runner. |
| Diminutive | Small/endearing — booklet, piglet. |

### 4.1.2 Number

| Pattern | Rule / Example |
|---|---|
| Regular | +s — books, dogs, ... |
| s/x/sh/ch/z/o | +es (most -o; foreign loans take -s) — boxes, potatoes; pianos, photos. |
| Consonant + y | y→i+es — cities, babies, ... |
| f/fe | →ves — leaves, knives, ... |
| Irregular | Vowel change — man→men, woman→women, child→children, tooth→teeth, foot→feet, mouse→mice, goose→geese, ox→oxen, person→people. |
| No change | Same form — sheep, deer, fish, series, species. |
| Foreign | Retain original plural — alumna→alumnae, criterion→criteria, phenomenon→phenomena, analysis→analyses, datum→data, medium→media, bacterium→bacteria, cactus→cacti, fungus→fungi, nucleus→nuclei, thesis→theses. |

### 4.1.3 Possession

| Pattern | Rule / Example |
|---|---|
| Singular | +'s — the cat's tail. |
| Plural regular | +' — the cats' house. |
| Plural irregular | +'s — the children's toys. |
| Names ending s | +'s or +' — James's / James'. |
| Inanimate | of-phrase preferred; 's for time/space — the leg of the table; tomorrow's weather. |
| Joint | Last noun only — Tom & Jerry's car. |
| Separate | Each noun — Tom's & Jerry's cars. |

- Double genitive: a friend of mine.

### 4.1.4 Countability & Crossover

- Mass→countable: a coffee(cup); two waters(bottle); an iron(appliance); a paper(document); a hair(strand).

## 4.2 Pronouns

### 4.2.1 Personal

- Pronoun replace noun; inflect person|number|gender|case. Position: Pronoun=Subject/Object/Preposition.

| Person | Subject | Object | Possessive determiner | Possessive pronoun | Reflexive |
|---|---|---|---|---|---|
| First singular | I | me | my | mine | myself |
| First plural | we | us | our | ours | ourselves |
| Second singular/plural | you | you | your | yours | yourself/yourselves |
| Third singular masculine | he | him | his | his | himself |
| Third singular feminine | she | her | her | hers | herself |
| Third singular neuter | it | it | its | its | itself |
| Third plural | they | them | their | theirs | themselves |

- singular they: Someone left their book.
- Preposition → object case: between you & me, for him & her.

### 4.2.2 Possessive

| Type | Form | Function |
|---|---|---|
| Determinative | my, your, his, her, its, our, their | Adjunct to noun — my book. |
| Independent | mine, yours, his, hers, ours, theirs | Standalone Noun Phrase — The book is mine. |

### 4.2.3 Reflexive & Intensive

- Reflexive: Object refers back to Subject — I cut myself.
- Intensive/Emphatic: Emphasizes antecedent — I myself saw it.

### 4.2.4 Reciprocal

- Mutual action — each other(two), one another(three+).

### 4.2.5 Relative

| Pronoun | Antecedent | Function / Example |
|---|---|---|
| who | person | Subject — the man who lives here. |
| whom | person | Object(formal) — the man whom I met. |
| which | thing/animal | Subject/Object — the book which is red. |
| that | person/thing | Subject/Object(defining only) — the man/book that I saw. |
| whose | person/thing | possessive — the man whose car is red. |
| where | place | Adverb — the house where I live. |
| when | time | Adverb — the day when we met. |
| why | reason | Adverb — the reason why I left. |

- Restrictive vs Non-restrictive: Restrictive = essential, no commas; Non-restrictive = extra, commas, that forbidden.

### 4.2.6 Interrogative

- Questions — who, whom, whose, which, what.

### 4.2.7 Demonstrative

| singular | plural | Function |
|---|---|---|
| this, that | these, those | Near/far from speaker. Determiner: This book. Pronoun: This is good. |

### 4.2.8 Indefinite

- Unspecific reference.

| Group | Words |
|---|---|
| Universal | all, another, any, anybody, anyone, anything, both, each, either, enough, everybody, everyone, everything. |
| Partitive | few, fewer, less, little, many, more, most, much, neither, nobody, none, no one, nothing, one, other, others, several, some, somebody, someone, something, such. |

### 4.2.9 Dummy/Expletive

- Fill structural Subject position without lexical content — it(weather/time/distance), there(existence).

## 4.3 Verbs

### 4.3.1 Classification

- Verb = action|state|occurrence; predicate nucleus. Position: Subject Verb Object; Auxiliary Verb; Modal Verb; to-infinitive; verb-ing.

| Type | Definition / Example |
|---|---|
| Lexical/Main | Full meaning — run, think, break. |
| Auxiliary | Tense/negation/helper — be, do, have. |
| Modal | Ability/obligation — can, could, may, might, shall, should, will, would, must, ought to, used to, need, dare. |
| Semi-modal | Conjugated like main verb — have to, be going to, be able to, be supposed to, had better. |
| Finite | Inflected for tense/person — He walks. |
| Non-finite | Infinitive, Participle, Gerund — to walk, walking, walked. |
| Intransitive | No Object — sleep, walk, happen. |
| Transitive | Requires Object — buy, love, eat. |
| Ditransitive | Two Objects — give, send, tell. |
| Linking/Copular | Subject → Complement — be, become, seem, look. |
| Ergative/Middle | Object becomes Subject without passive — The door opened; The book sells well. |
| Complex transitive | Object + Complement — They elected him leader. |
| Phrasal | Verb + particle — give up, take off. |
| Prepositional | Verb + Preposition — look after, listen to. |
| Phrasal-prepositional | Verb + particle + Preposition — put up with, look forward to. |
| Regular | past tense/-ed — walk→walked. |
| Irregular | See 4.3.3. |
| Stative | State, not continuous — know, believe, prefer, own, belong, seem. |
| Dynamic | Action — run, eat, sleep, write. |

### 4.3.2 Forms

| Form | Label / Use |
|---|---|
| Base | Verb — Present plural; after modal. |
| Third person | Verb-s/es — Present singular. |
| Past | past tense/-ed — Simple past. |
| Past participle | past participle — Perfect; passive. |
| Present participle | verb-ing — Continuous; gerund; Adjective. |
| To-infinitive | to-infinitive — Purpose; Subject; Object. |
| Bare infinitive | infinitive without to — after modal, make, let, have, see, hear. |

### 4.3.3 Irregular Patterns

| Pattern | Rule / Example |
|---|---|
| Invariant | Base=Past=Participle — cut, put, shut. |
| Vowel change | Base→Past→Participle(same) — find→found→found, sit→sat→sat. |
| Vowel + -en | Base→Past→Participle(-en) — break→broke→broken, speak→spoke→spoken. |
| Ablaut | Vowel gradation — sing→sang→sung, drink→drank→drunk. |
| Weak | Dental suffix but irregular — bring→brought, buy→bought. |
| Mixed | Weak past, strong participle — show→showed→shown. |
| Suppletive | Stem replacement — be→was/were→been, go→went→gone, good→better→best. |
| Zero | No change in some forms — put→put→put. |
| Defective | Missing forms — can→could(*canned), may→might(*mayed). |

### 4.3.4 Complementation

| Pattern | Structure / Triggers |
|---|---|
| Gerund | Verb + verb-ing — enjoy, mind, finish, avoid, spend time, be worth, can't help. |
| Infinitive | Verb + to-infinitive — want, hope, decide, plan. |
| Preposition + Gerund | Preposition + verb-ing — look forward to, object to, be used to, tired of, prevent from. |
| Bare infinitive | Verb + Object + bare infinitive — make, let, have. |
| Object infinitive | Verb + Object + to-infinitive — advise, encourage, ask, tell. |
| Object gerund | Verb + Object + verb-ing — catch, find, hear, see. |
| Adjective + infinitive | Adjective + to-infinitive — afraid, eager, likely, ready. |
| Get + Adjective/Prepositional Phrase | get + Adjective / past participle — get married, get lost, get tired. |

- Shift: I think he is right(opinion) versus I am thinking about it(process).

### 4.3.5 Gerund versus Present Participle

| Feature | Gerund | Present Participle |
|---|---|---|
| Function | Noun | Part of Verb phrase or Adjective. |
| Position | Subject, Object, complement after Preposition. | After auxiliary be; before/after noun. |
| Example | Swimming is good. / I enjoy swimming. | She is swimming. / a swimming pool. |

- Test: replace with "it" → gerund; replace with Adjective → participle.

### 4.3.6 Gerund versus Infinitive Meaning Shifts

| Verb | Gerund | Infinitive |
|---|---|---|
| stop | quit — stop smoking. | pause in order to — stop to smoke. |
| remember | past memory — remember meeting him. | future obligation — remember to call him. |
| forget | lost memory — forget meeting him. | failed obligation — forget to call him. |
| try | experiment — try opening it. | attempt — try to open it. |
| regret | past regret — regret telling him. | bad news(formal) — regret to tell you. |

- Help + (to) infinitive: He helped me (to) carry it.
- Need + verb-ing: passive meaning. The car needs washing. = The car needs to be washed.

### 4.3.7 Modals

| Function | Modals / Example |
|---|---|
| Ability | can, could, be able to — I can swim. / could=general past; was/were able to=specific past achievement. |
| Permission | can, could, may — You may enter. |
| Obligation | must, have to, need to — I must go.(internal) / I have to go.(external). |
| Prohibition | mustn't, can't — You can't smoke here. |
| Advice | should, ought to, had better — You should rest. |
| Possibility | may, might, could — It might rain.(might &lt; may). |
| Deduction | must, can't — He must be tired. |
| Offer/Request | shall, will, would, can, could — Can I help? |
| Past habit | would, used to — He would walk daily. / I used to smoke. |

- May/Might as well = no better alternative.
- Dare/Need modal versus main: Modal: Need he go? He needn't go.(no -s, no do-support). Main: Does he need to go? He doesn't need to go.
- be/get used to + Noun/verb-ing = accustomed(state/process).

### 4.3.8 Modal Perfects

| Modal Perfect | Use / Example |
|---|---|
| must have + past participle | Certain past deduction — He must have left. |
| can't have + past participle | negative past deduction — She can't have seen us. |
| might have + past participle | Possible past event — He might have forgotten. |
| could have + past participle | Unrealized past possibility — You could have told me! |
| should have + past participle | Past criticism/regret — You should have studied. |
| needn't have + past participle | Unnecessary but done — I needn't have brought it. |
| didn't need to + Verb | Unnecessary (not done) — I didn't need to bring it. |

### 4.3.9 Phrasal Verbs

| Type | Rule / Example |
|---|---|
| Intransitive | No Object — catch on, get up, break down. |
| Transitive Separable | Object can split Verb & particle; Pronoun Object MUST split — turn off the light / turn it off (*turn off it). |
| Transitive Inseparable | Object always follows particle — look after the baby (*look the baby after). |
| Three-part | Verb + particle + Preposition. Always inseparable — put up with the noise / put up with it. |

## 4.4 Adjectives

### 4.4.1 Position & Order

- Adjective modify noun; appear prenominally or after Linking Verb. Position: Determiner Adjective Noun; Subject Linking Verb Adjective. Order: Opinion→Size→Age→Shape→Colour→Origin→Material→Purpose. Example: a beautiful small old round red Italian wooden writing desk.
- Attributive: before noun — a red car.
- Predicative: after Linking Verb — The car is red.
- Postpositive: after noun — something important, attorney general.

### 4.4.2 Types

| Type | Definition / Example |
|---|---|
| Proper | From proper noun — Victorian, Shakespearean. |
| Participial | Present(boring) | Past(bored). |
| Compound | good-looking, brand-new. |
| Denominal | From noun — wooden, metallic. |
| Deverbal | From verb — running water, broken heart. |
| Gradable | Can take degree — very tall, more important. |
| Non-gradable/Absolute | Extreme or binary — unique, dead, perfect. |
| Coordinate | Equal modification — nice and warm. |
| Cumulative | Layered modification — a beautiful big table. |

### 4.4.3 Comparison

| Degree | Short (1 syllable; 2 syllables -y,-ow,-le) | Long (2+ syllables; other 2-syllable) |
|---|---|---|
| Equal | as tall as | as beautiful as |
| Comparative | taller than | more beautiful than |
| Superlative | the tallest | the most beautiful |
| Inferior | less tall than | less beautiful than |
| Least | the least tall | the least beautiful |

| Spelling | Rule / Comparative / Superlative |
|---|---|
| Consonant-Vowel-Consonant (1 syllable) | double consonant + er/est — bigger / biggest. |
| Consonant + y | y→i + er/est — happier / happiest. |
| silent e | +r/st — nicer / nicest. |
| 2+ syllables (most other 2-syllable) | more/most + Adjective — more careful / most careful. |

- Irregular: good→better→best, bad→worse→worst, far→farther/further→farthest/furthest, little→less→least, many/much→more→most.
- fewer=countable (fewer books); less=uncountable (less water).
- Double comparative: more & more beautiful.
- Proportional: The more you study, the more you know.

## 4.5 Adverbs

### 4.5.1 Types

- Adverb modify verb, adjective, adverb, or entire clauses.

| Type | Question / Example |
|---|---|
| Manner | How? — quickly, well, carefully, hard, fast. |
| Place | Where? — here, there, everywhere. |
| Time | When? — yesterday, now, later, soon. |
| Frequency | How often? — always, usually, often, sometimes. |
| Duration | How long? — briefly, permanently, temporarily. |
| Degree | How much? — very, too, quite, rather, almost. |
| Focusing | Restrictive(only, just, simply) | Additive(also, even, too). |
| Sentence/Disjunct | Style(frankly, honestly) | Attitude(luckily, unfortunately, obviously). |
| Conjunct/Linking | Additive(furthermore, moreover) | Adversative(however, nevertheless) | Causal(therefore, thus) | Temporal(then, meanwhile). |
| Stance | Speaker comment — apparently, presumably. |
| Flat adverbs | Same form as Adjective — fast, hard, late, high, straight. |

### 4.5.2 Position Rules

- Position: Adverb Verb; Auxiliary Adverb Verb; Verb Object Adverb; Adverb Adjective; Adverb Adverb; Adverb, Subject Verb.

| number | Position / Example |
|---|---|
| 1 | Before main verb — She always eats. |
| 2 | After be — He is always late. |
| 3 | Between Auxiliary & Verb — He has never eaten. |
| 4 | After intransitive verb — He runs fast. |
| 5 | After Object — He eats rice quickly. |
| 6 | Sentence-initial/final — Yesterday, I left. |
| 7 | Before Adjective/Adverb — Very good. |

- Multi-Adverb: Manner→Place→Time. She sang beautifully in Paris last night.
- already=sooner than expected; yet=up to now(question/negative); still=continuing.
- also(before main verb/after be, affirmative); too(end, affirmative); as well(end, affirmative); either(end, negative).
- Only position changes meaning: Only I saw him(affirmative); I only saw him(not speak); I saw only him(affirmative).

### 4.5.3 Comparison & Degree

| Structure | Use / Example |
|---|---|
| so + Adjective/Adverb | Degree — so beautiful, so fast. |
| so + Adjective + a/an + Noun(singular) | Degree with singular countable — so beautiful a day. |
| such + a/an + Adjective + Noun(singular) | Emphasis on noun — such a beautiful day. |
| such + Adjective + plural/uncountable Noun | Emphasis on noun — such beautiful flowers. |
| too + Adjective/Adverb [+for Object] + to-infinitive | Excess → negative result — too young to marry. |
| Adjective/Adverb + enough [+for Object] + to-infinitive | Sufficiency — old enough to vote. |
| enough + Noun | Sufficiency (noun) — enough money. |

## 4.6 Determiners

### 4.6.1 Predeterminers

- Precede central Determiner. Position: Predeterminer + Determiner + Noun.

| Predeterminer | Use / Example |
|---|---|
| all, both, half | All the students; both my friends; half an hour. |
| double, twice, three times | Double the amount; twice the price. |
| such, what | Such a shame; What a day! |

### 4.6.2 Articles

- Articles mark definiteness & select countability. Position: Determiner Adjective Noun.

| Article | Condition / Example |
|---|---|
| a/an | First mention; jobs; singular countable; per-unit rate — a book, an apple, a doctor, a university, an hour, twice a week. |
| the | Unique; second mention; superlatives; ordinals; rivers; ranges; inventions; instruments; specific groups — the sun, the Thames, the best, the guitar, the rich, the Vietnamese. |
| zero (ø) | Meals; sports; languages; abstract(general); proper names; subjects; transport; institutions; plural generics — breakfast, football, English, Paris, by car, at school, Cats sleep. |

- A versus An by pronunciation: an hour, an MBA; a university, a European.
- Abstract Noun: zero = general (Love is blind); the = specific (The love he felt).
- Plural countable Noun + zero = general class (Dogs bark; The dogs = specific pack).
- some in questions expecting affirmative: Would you like some coffee?

### 4.6.3 Demonstratives & Possessives

| Type | singular | plural | Function |
|---|---|---|---|
| Demonstrative | this, that | these, those | Near/far from speaker. |
| Possessive determiner | my, your, his, her, its | our, your, their | Adjunct to noun. |
| Possessive Pronoun | mine, yours, his, hers, its | ours, yours, theirs | Standalone Noun Phrase. |

### 4.6.4 Quantifiers

| Quantifier | countable | uncountable | Connotation |
|---|---|---|---|
| many / a few / few | yes | no | a few(positive); few(negative). |
| much / a little / little | no | yes | a little(positive); little(negative). |
| plenty of / a lot of / lots of | yes | yes | informal. |
| some / any | yes | yes | some(positive); any(question/negative). |
| more / most | yes | yes | — |

- much → mainly negative/question; a lot of/plenty of → affirmative.
- no + Noun = not any + Noun: I have no time = I don't have any time.
- Quantifier + of + Determiner: most of the, some of my, none of these.
- any + affirmative = "it does not matter which": You may take any book.

### 4.6.5 Group Quantifiers

| Word | number / Use / Example |
|---|---|
| each | ≥2 — Individual members — Each student passed. |
| every | ≥3 — Group as whole — Every student passed. |
| all | ≥2 — Entire set — All students passed. |
| both | 2 — Pair together — Both students passed. |
| either | 2 — One of two — Either option works. |
| neither | 2 — not one of two — Neither option works. |
| none | ≥3 — not any — None of them passed. |

- each ≥2 items; every ≥3.
- both / either / neither precede singular noun directly: both cars, either day, neither answer.
- All of / Both of / None of + Determiner + Noun: All of the students, None of my friends.

### 4.6.6 Numerals

| Type | Form / Rule / Example |
|---|---|
| Cardinal | one, two, twenty, hundred, thousand, million — No plural S when counting: two hundred. Plural in indefinites: hundreds of. |
| Ordinal | first, second, third, + -th (fifth, twelfth, twentieth) — The first chapter. |
| Fraction | 1/2 = a half; 1/3 = a third; 2/3 = two-thirds (plural numerator >1) — three-quarters. |
| Multiplicative | once, twice, three times. |

### 4.6.7 Distributives

- Refer to members of a group individually — all, both, either, neither, each, every.

### 4.6.8 Interrogatives

- which, what, whose — Which book? What colour? Whose car?

### 4.6.9 Postdeterminers

- Follow central Determiner — many, several, few, last, next, past, cardinal/ordinal numerals: the many problems, the last time.

### 4.6.10 Alternatives

| Word | Use / Example |
|---|---|
| another | + singular noun (one more) — I need another cup. |
| another | + number + plural noun — I need another two days. |
| other | + plural noun (additional/different) — I have other books. |
| others | = other + plural noun (indefinite remainder) — Some left; others stayed. |
| the other | + singular noun (second of two) — One is red, the other is blue. |
| the others | = the other + plural noun (definite remainder) — Three came; the others stayed. |

## 4.8 Conjunctions

### 4.8.1 Coordinating

- Join elements of equal syntactic status. Position: Clause Conjunction Clause; X Conjunction Y.
- for, and, nor, but, or, yet, so (FANBOYS).
- Asyndetic = no Conjunction; Syndetic = one Conjunction; Polysyndetic = multiple Conjunctions.

### 4.8.2 Subordinating

| Category | Conjunctions / Example |
|---|---|
| Time | after, although, as, as soon as, before, once, since, till, until, when, whenever, while — When I came, he left. |
| Place | where, wherever — Where there is smoke, there is fire. |
| Manner | as, as if, as though, how — Do as I say. |
| Reason/Cause | because, since, as, given that, inasmuch as, now that — Because it rained, we stayed. |
| Purpose | so that, in order that, lest — He ran so that he could catch it. |
| Result | so…that, such…that — He was so tired that he slept. |
| Condition | if, unless, provided that, as long as, in case — If you try, you will win. |
| Concession | although, though, even though, even if, while, whereas, albeit — Although it rained, we went. |
| Comparison | than, as, as…as, whether — He is taller than I am. |

- Subordinating Conjunction → Dependent Clause; no comma when Dependent Clause follows main.

### 4.8.3 Correlative

- Paired parallel structure required. both…and, either…or, neither…nor, not only…but also, whether…or, as…as, such…that, so…that, no sooner…than, hardly…when.

### 4.8.4 Conjunctive Adverbs/Transitions

- however, therefore, moreover, furthermore, nevertheless, nonetheless, consequently, accordingly, hence, thus, otherwise, instead, besides, also, still, yet, meanwhile, subsequently, eventually, previously.

# 5 PHRASE STRUCTURE: The Constituent Units

## 5.1 Phrase Types

- Phrases = single grammatical units built around head word.

| Type | Head | Structure / Example |
|---|---|---|
| Noun Phrase | Noun | (Predeterminer) + (Determiner) + (Adjective Phrase) + Noun + (Prepositional Phrase/Relative Clause/Participle phrase/Infinitive phrase/Appositive phrase/Adjective phrase) — a very beautiful girl in red. |
| Verb Phrase | Verb | Auxiliary/Modal + (Adverb) + Verb + (Object/Complement) — will quickly finish the work. |
| Adjective Phrase | Adjective | (Adverb) + Adjective + (Prepositional Phrase/Clause) — extremely intelligent. |
| Adverb Phrase | Adverb | (Adverb) + Adverb — very carefully. |
| Prepositional Phrase | Preposition | Preposition + Noun Phrase/Pronoun/Clause — in the big city. |

## 5.2 Phrase Structure Rules

### 5.2.1 Functions within Phrases

- Head: obligatory; determines phrase category.
- Specifier: marks phrase boundary — Determiner in Noun Phrase, degree word in Adjective Phrase.
- Modifier: optional; adds information — Premodifier(before head), Postmodifier(after head).
- Complement: completes head meaning; selected by head — transitive Verb → Object; Preposition → Noun Phrase.

### 5.2.2 Recursive Embedding

- Phrases embed within phrases: Prepositional Phrase inside Noun Phrase (the man in the hat), Relative Clause inside Noun Phrase (the book that I read), clause inside Noun Phrase (the idea that he left).
- Recursion → indefinitely complex structures.

# 6 CLAUSE STRUCTURE: The Propositional Units

## 6.1 Clause Elements

| Element | Definition / Types / Example |
|---|---|
| Subject | Simple, Compound, Complex, Expletive/Dummy(it, there), Implied(imperative). — The cat sleeps. / It is raining. |
| Predicate | Verb + Objects/Complements/Adverbials. |
| Verb | Finite, Non-finite. |
| Object | Direct(gave a book), Indirect(gave me a book), Prepositional(gave a book to me), Retained(passive: I was given a book), Cognate(die a death). |
| Complement | Subject Complement/Predicative(She is happy), Object Complement(They elected him leader). |
| Adverbial / Adjunct | Time, Place, Manner, Reason, Purpose, Result, Condition, Concession, Degree, Frequency, Instrument, Agent, Standard, Accompaniment, Matter, Respect. |
| Disjunct | Style(frankly) | Content(obviously). |
| Conjunct | Linking adverbial — however, therefore. |

## 6.2 Clause Types by Dependency

### 6.2.1 Independent versus Dependent

Independent Clause: Subject + finite Verb; stands alone as sentence.
Dependent Clause: Subject + finite Verb; cannot stand alone; functions as Subject|Object|Complement|modifier within matrix clause.

### 6.2.2 Coordination versus Subordination

- Coordination: joins elements of equal syntactic status (Independent Clause+Independent Clause; Noun Phrase+Noun Phrase).
- Subordination: embeds Dependent Clause within matrix clause, creating asymmetry.
- Dependency: matrix clause = head; subordinate clauses = dependents.

### 6.2.3 Clause Types by Function

| Type | Function | Introducer | Example |
|---|---|---|---|
| Noun clause | Subject, Object, complement | that, whether, if, wh-words | I know that he is here. |
| Relative (Adjective) clause | Postmodify noun | who, whom, which, that, whose, where, when, why | the man who lives here. |
| Adverbial clause | Modify verb/clause | when, because, if, although, so that, ... | When I came, he left. |

- Restrictive vs Non-restrictive: Restrictive = essential identification, no commas; Non-restrictive = supplementary, commas.

## 6.3 Clause Patterns

| Pattern | Formula / Example |
|---|---|
| SV | Subject + Verb(intransitive) — I sleep. |
| SVO | Subject + Verb + Object(monotransitive) — I love English. |
| SVC / SPC | Subject + Linking Verb + Complement — She looks happy. |
| SVA | Subject + Verb(intransitive) + Adverbial — She lives in Paris. |
| SVOO / SVIOO | Subject + Verb + Indirect Object + Direct Object — He gave me a gift. |
| SVOC | Subject + Verb + Object + Complement — They elected him leader. |
| SVOA | Subject + Verb + Object + Adverbial — She put the book on the shelf. |

## 6.4 Non-finite Clauses

| Type | Form / Example |
|---|---|
| To-infinitive clause | To leave now would be rude. |
| Bare infinitive clause | I saw him leave. |
| -ing Participle clause | Walking down the street, he saw her. |
| -ed Participle clause | Seen from above, the city looks small. |
| Verbless clause | Whatever the reason, he refused. |
| Small clause | Object + bare infinitive/Adjective/Noun without finite Verb — I saw him run; They made him angry. |

## 6.5 Special Clause Types

### 6.5.1 Cleft Sentences

- It is/was + [emphasised] + that/who/which + …

| Type | Example |
|---|---|
| It-cleft | It was John who broke the window. / It was yesterday that he left. |
| Wh-cleft / Pseudo-cleft | What I need is more time. |
| Inverted pseudo-cleft | More time is what I need. |
| All-cleft | All I want is peace. |

### 6.5.2 Existential there

- There + be + Noun Phrase — There is a book on the table. / There exist several solutions.

### 6.5.3 Inversion

| Trigger | Formula / Example |
|---|---|
| Locative | Prepositional phrase + Verb + Subject — On the hill stood a castle. |
| Negative adverbial | Never/Hardly/Scarcely/Rarely/Seldom/Little/Nowhere + Auxiliary + Subject + Verb — Never have I seen this. |
| Subject-operator | Auxiliary/Be/Modal + Subject + main verb — Are you coming? |
| Only + phrase | Only then/after/by… + Auxiliary + Subject + Verb — Only then did I understand. |
| Not until | Not until + time + Auxiliary + Subject + Verb — Not until yesterday did I know. |
| So + Adjective/Adverb + that | So + Adjective/Adverb + Auxiliary + Subject + Verb + that — So beautiful was she that everyone stared. |
| Were/Should/Had (omitting if) | Were + Subject…, Should + Subject…, Had + Subject + past participle… — Were I you, I would go. |
| Here/There | Here/There + Verb + Subject — Here comes the bus. |

# 7 SENTENCE TAXONOMY: The Complete Units

## 7.1 By Structure

| Structure | Composition |
|---|---|
| Simple | 1 Independent Clause. |
| Compound | 2+ Independent Clauses (FANBOYS or ;). |
| Complex | 1 Independent Clause + 1+ Dependent Clauses. |
| Compound-Complex | 2+ Independent Clauses + 1+ Dependent Clauses. |

## 7.2 By Purpose / Mood

### 7.2.1 Declarative

- Statement — positive or negative. Subject + Verb + Object.

### 7.2.2 Interrogative

| Type | Formula / Example |
|---|---|
| Polar/Yes-no | Auxiliary/Be/Modal + Subject + Verb? — Do you swim? |
| Wh-/Constituent/Information | Wh-word + Auxiliary/Be/Modal + Subject + Verb? — Where did he go? |
| Tag | Statement + mini-question — You are coming, aren't you? |
| Alternative | Auxiliary + Subject + Verb, or …? — Do you want tea or coffee? |
| Rhetorical | Question expecting no answer — Who cares? |
| Declarative question | Statement intonation rising — You're leaving? |
| Echo question | Repeat for clarification — He did what? |

### 7.2.3 Imperative

| Type | Form / Example |
|---|---|
| Second person | Bare infinitive — (You) Sit down. |
| First person inclusive | Let's + bare infinitive — Let's go. |
| Third person | Let him/her/them + bare infinitive — Let them eat cake. |
| Negative | Do not/Don't + bare infinitive — Don't touch. / Let's not argue. |
| Emphatic | Do + bare infinitive — Do sit down. |

### 7.2.4 Exclamatory

- What + (a/an) + Adjective + Noun — What a day!
- How + Adjective/Adverb + Subject + Verb — How fast he runs!
- Such + (a/an) + Adjective + Noun — Such a beautiful day!
- So + Adjective/Adverb — So beautiful!

## 7.3 By Form / Completeness

| Form | Definition / Example |
|---|---|
| Major sentence | Full Subject + Predicate structure. |
| Minor sentence | Elliptical(Yes.), Formulaic(Hello.), Exclamatory(Wow!), Interjectional(Ouch!). |
| Fragment | Incomplete — Because it rained. (fix: attach to main). |
| Run-on / Fused sentence | Two Independent Clauses without punctuation/Conjunction — The movie was entertaining it kept us engaged. (fix: add period, semicolon, or Conjunction). |
| Comma splice | Two Independent Clauses joined by comma only — The movie was entertaining, it kept us engaged. (fix: add Conjunction or use ;/.). |

## 7.4 Sentence Styles

| Style | Definition / Example |
|---|---|
| Periodic / Suspensive | Main clause last; builds suspense — Despite the rain, because he had promised, he went. |
| Loose / Cumulative | Main clause first; modifiers follow — He went, despite the rain, because he had promised. |
| Balanced / Parallel | Equal structure on both sides — It was the best of times, it was the worst of times. |
| Paratactic | Clauses of equal weight, often coordinated — I came, I saw, I conquered. |
| Hypotactic | Subordination of clauses — When I arrived, because I had been summoned, I entered. |

# 8 THE CORE GRAMMATICAL SYSTEMS

## 8.1 Tense

### 8.1.1 Present

| Form | Formula | Use / Markers |
|---|---|---|
| Simple | Verb(-s/-es) | Habit, fact, schedule — always, usually, every day. |
| Continuous | am/is/are + verb-ing | Now, temporary, future plan — now, currently, today. |
| Perfect | have/has + past participle | Past→now, experience, result — just, already, yet, ever, never, since, for. |
| Perfect Continuous | have/has been + verb-ing | Duration up to now — all day, for hours, lately. |

### 8.1.2 Past

| Form | Formula | Use / Markers |
|---|---|---|
| Simple | past tense/-ed | Completed past — yesterday, ago, last week. |
| Continuous | was/were + verb-ing | Interrupted action, background — at 8pm yesterday, while. |
| Perfect | had + past participle | Earlier past — before, by the time, already. |
| Perfect Continuous | had been + verb-ing | Duration before past point — for hours, since morning. |

### 8.1.3 Future

| Form | Formula | Use / Markers |
|---|---|---|
| Simple | will + Verb | Prediction, promise — tomorrow, next week, soon. |
| Continuous | will be + verb-ing | In progress at future time — at this time tomorrow. |
| Perfect | will have + past participle | Completed before future point — by tomorrow, by 2030. |
| Perfect Continuous | will have been + verb-ing | Duration up to future point — by next year, for ten years. |

- Other future expressions: be going to(intention/evidence), present progressive(fixed arrangement), simple present(schedule), be about to(imminent), be to(formal plan/order), be due to(scheduled expectation), be bound to(certainty), be likely/unlikely to(probability).
- Future in the Past: He said he would go. / I was going to call.
- Time Clause Constraint: Present tense for future meaning in subordinate time/condition clauses — When I arrive, I will call you.

## 8.2 Aspect

| Aspect | Meaning |
|---|---|
| Simple | Complete fact, habit, general truth. |
| Progressive/Continuous | Ongoing, temporary, background, process. |
| Perfect | Before another time point; current relevance. |
| Perfect Progressive/Continuous | Duration up to a time point; temporary + complete. |

## 8.3 Mood

### 8.3.1 Indicative

- Default mood for statements, questions, & factual assertions.

### 8.3.2 Imperative

- Bare infinitive form; implied Subject you.
- Negative: Do not + bare infinitive. / Let's not + bare infinitive.

### 8.3.3 Subjunctive

| Type | Form / Trigger / Example |
|---|---|
| Mandative/Present | that + Subject + bare infinitive after demand/suggestion — I suggest that he go. (Verbs: suggest, demand, order, insist, require, recommend, propose, advise). |
| Were-subjunctive/Past | were for all persons in formal English — If I were rich / I wish he were here / as it were. |
| Formulaic | Frozen expressions — long live, be that as it may, come what may, God save. |

### 8.3.4 Conditional

| Type | If-clause | Main clause | Use |
|---|---|---|---|
| 0 | If + Simple Present | Simple Present | Universal truth. |
| 1 | If + Simple Present | will/can/may + Verb | Real future possibility. |
| 2 | If + Simple Past (were) | would/could/might + Verb | Unreal present. |
| 3 | If + Past Perfect | would/could/might have + past participle | Unreal past. |
| Mixed | If + Past Perfect | would/could + Verb | Past condition → present result. |
| Inverted (no if) | Had/Should/Were + Subject… | main clause | formal equivalent. |

| Variation | Meaning |
|---|---|
| Unless | = if…not. |
| Provided (that) / As long as | Conditional requirement. |
| But for + Noun | = if it were not for / if it had not been for. |
| Otherwise / Or else | negative result. |
| In case + clause | Precaution (do X to prevent Y). |

- Inverted: Were I you, I would go. / Had I known, I would have acted. / Should you see him, tell him.
- In case(precaution) versus If(condition): Take an umbrella in case it rains. / If it rains, take an umbrella.

## 8.4 Voice

| Voice | Definition / Example |
|---|---|
| Active | Subject performs action — The dog bit the man. |
| Passive | Subject receives action — The man was bitten by the dog. Formula: Subject + BE + past participle/-ed [+ by-agent]. |
| Long agentive passive | by-phrase included — The cake was eaten by the children. |
| Short agentless passive | No by-phrase — The cake was eaten. |
| Get-passive | Informal — He got fired. |
| Stative passive | State, not action — The door is closed. |
| Adjectival passive | Participle as Adjective — I am interested. |
| Middle | No agent; generic Subject — The book sells well. / This car drives smoothly. |

### 8.4.1 Passive by Tense

| Tense | Passive Formula |
|---|---|
| Simple Present | am/is/are + past participle |
| Present Continuous | am/is/are being + past participle |
| Present Perfect | have/has been + past participle |
| Simple Past | was/were + past participle |
| Past Continuous | was/were being + past participle |
| Past Perfect | had been + past participle |
| Simple Future | will be + past participle |
| Future Perfect | will have been + past participle |
| Modal | modal + be + past participle |
| Modal Perfect | modal + have been + past participle |

### 8.4.2 Special Cases

| Case | Active / Passive |
|---|---|
| Double object | He gave me a book. → I was given a book. / A book was given to me. |
| Object complement | They elected him leader. → He was elected leader. |
| Reporting | People say that he left. → It is said that he left. / He is said to have left. |

- Phrasal Verb retain particle in passive: The meeting was called off.

| Transferred negation | I don't think he is here, is he? |
| Double negative / Negative concord | Two negatives reinforce in non-standard; cancel in standard. |
| Non-assertive forms | any, ever, yet, anymore — I don't have any. |

- Do-support: no Auxiliary/Modal present → insert do/does/did: I do not eat. / He does not go. / They did not leave.
- Required for: questions(Do you go?); negation(I don't go); emphasis(I do go); substitution(He likes it more than I do).
- Blocked when Auxiliary/Modal present: Are you going? /*Do you be going?/

## 8.7 Agreement / Concord

| Pattern | Verb / Example |
|---|---|
| Subject1 & Subject2 (separate) | plural — Cats & dogs are cute. |
| Subject1 & Subject2 (compound) | singular — Bread & butter is breakfast. |
| Everyone/Someone/Each/Every/No one/Neither/Either | singular — Everyone has a dream. |
| Gerund/Infinitive/Clause as Subject | singular — Swimming is good. |
| Money/time/distance as unit | singular — Ten dollars is enough. |
| Neither…nor / Either…or / Not only…but also | Nearest Subject — Either you or he is wrong. / Not only the teacher but also the students are here. |
| Subject1 + along with / as well as / together with | Follows Subject1 — I, as well as them, am here. |
| A number of + plural Noun | plural — A number of students are absent. |
| The number of + plural Noun | singular — The number is 50. |
| The + Adjective (group) | plural — The rich are not always happy. |
| Fraction/percentage + of + Noun | Follows Noun — 50% of the water is gone. |
| Collective Noun (team, family…) | Unit=singular; members=plural — The team is winning / are arguing. |

- None: formal singular(None is); widely accepted plural(None are).

## 8.8 Question Formation

| Type | Formula / Example |
|---|---|
| Yes/No | Auxiliary/Be/Modal + Subject + Verb? — Do you swim? / Is he here? |
| Wh-Subject | Wh-word + Verb? (no inversion) — Who broke it? / What happened? |
| Wh-Object/Adverb | Wh-word + Auxiliary/Be/Modal + Subject + Verb? — Where did he go? |
| Choice | Auxiliary + Subject + Verb, or …? — Do you want tea or coffee? |
| Embedded | Subject + Verb + wh-word + Subject + Verb — I know where he is. |
| Negative | Auxiliary + not + Subject + Verb? — Don't you like it? |
| Why + bare infinitive | Why + bare infinitive? — Why leave now? |

- Embedded questions use statement word order; no inversion or question mark.
- Negative questions express confirmation, exasperation, or invitations.

### 8.8.1 Tag Questions

| Main Clause | Tag |
|---|---|
| I am… | aren't I? |
| Let's… | shall we? |
| Imperative | will you? / won't you? |
| Nobody/Nothing/Never/Hardly/Scarcely/Seldom | affirmative tag |
| There is/are | isn't/aren't there? |
| This/That/These/Those + be | isn't/aren't it/they? |
| Have (possession) | haven't/hasn't…? |
| Had better | hadn't…? |
| Used to | didn't…? / usedn't…? |

- Transfer of negation: I don't think he is here, is he?

### 8.8.2 Short Answers & Agreement

| Function | Formula / Example |
|---|---|
| Affirmative short answer | Yes, Subject + Auxiliary — Yes, I do. |
| Negative short answer | No, Subject + Auxiliary + not — No, I don't. |
| Affirmative agreement | So + Auxiliary + Subject — So do I. |
| Negative agreement | Neither/Nor + Auxiliary + Subject — Neither do I. |

- Agreement inversions require same Auxiliary as original clause. I like it. → So do I. / I can swim. → So can I.
- So + Subject + Auxiliary = affirmation, not agreement. You like it. → So I do. (=indeed)

## 8.9 Causative

| Structure | Meaning / Example |
|---|---|
| have + Object + bare infinitive | Cause somebody to do — I had him repair it. |
| have + Object + past participle | Arrange / experience — I had my car repaired. / I had my wallet stolen. |
| get + Object + to-infinitive | Persuade / cause — I got him to repair it. |
| get + Object + past participle | Arrange — I got my car repaired. |
| make + Object + bare infinitive | Force / compel — He made me laugh. |
| let + Object + bare infinitive | Allow / permit — Let me go. |

- Have somebody do(they do it). Get somebody to do(persuade). Make somebody do(force). Let somebody do(allow).

# 9 PUNCTUATION, MECHANICS & COHESION

## 9.1 Terminal Marks

| Mark | Function |
|---|---|
| Period / Full stop | End declarative sentence, abbreviation. |
| Question mark | End direct question. |
| Exclamation mark | End exclamation, command, interjection. |

## 9.2 Internal Pauses & Connectors

### 9.2.1 Comma

| Use | Pattern / Example |
|---|---|
| FANBOYS | Independent Clause , coordinating conjunction Independent Clause — She ran, but he walked. |
| Introductory | Word/phrase/clause before main clause — However, I disagree. |
| Non-restrictive | Element not essential to identity — My brother, a doctor, lives here. |
| Series | Three or more items (Oxford optional) — red, white, & blue. |
| Direct address | Name or title — John, please stop. |
| Dates/Addresses | Separate elements — 4 July 2026 / Austin, Texas. |
| Tag question | Before tag — You are coming, aren't you? |
| Coordinate adjectives | Adjectives independently modifying noun — a big, red car. |
| Parenthetical | Interrupter — The answer, however, is no. |
| Direct speech tag | He said, "I am tired." |
| Vocative | Direct address — Sir, please. |
| Absolute phrase | Weather permitting, we will go. |

### 9.2.2 Semicolon

- Join closely related Independent Clauses without coordinator — She ran; he walked.
- Complex series with internal commas — Paris, France; Berlin, Germany; Rome, Italy.
- Before conjunctive Adverb — He ran; however, she walked.

### 9.2.3 Colon

- After Independent Clause before list/explanation/quotation — He had one goal: to win.
- Apposition, title/subtitle, ratio, time, formal letter salutation.

### 9.2.4 Dash / Em-dash

- Parenthetical break, emphasis, interruption, appositive, summary, afterthought — The answer — though surprising — was yes.

### 9.2.5 En-dash

- Ranges, compound adjectives — pages 5–10, the London–Paris flight.

### 9.2.6 Hyphen

- Compound modifier before Noun — well-known author.
- Compound numbers — twenty-one.
- Prefixes before proper Noun — anti-American.
- Word division at line break.
- Suspended compounds — three- and four-year-olds.

### 9.2.7 Ellipsis

- Omission, hesitation, trailing off — "I wonder…"

### 9.2.8 Apostrophe

| Use | Rule / Example |
|---|---|
| Possession | Section 4.1.3. Mark: 's, '. |
| Contraction | Omitted letters — it's, don't, can't. |
| Plural of letters/numbers/words | 's (to avoid confusion) — mind your p's & q's, the 1990's. |

- Apostrophes do not form plural of ordinary Noun: apples (not apple's).
- it's=it is; its=possessive. Same for who's/whose, you're/your.

### 9.2.9 Parentheses / Brackets

| Type | Use |
|---|---|
| Round ( ) | Supplementary info, asides. |
| Square [ ] | Editorial insertion, clarification. |
| Curly { } | Sets, mathematical notation. |
| Angle &lt; &gt; | Technical notation, URLs, placeholders. |

### 9.2.10 Quotation Marks

- Double " " : American direct speech, titles of short works.
- Single ' ' : British outer quotation, nested quotation inside double.

### 9.2.11 Slash / Virgule

- Alternatives — and/or.
- Fractions — 3/4.
- Per — km/h.
- Line breaks in poetry or URLs.

### 9.2.12 Other Marks

| Mark | Use |
|---|---|
| Ampersand & | Names, informal lists — Smith & Jones. |
| Bullet point • | List items. |
| Asterisk * | Footnote, wildcard, omission. |
