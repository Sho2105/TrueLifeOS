## CÁC DẠNG CÂU CƠ BẢN THEO 12 THÌ

Cấu trúc câu đơn giản:  
Subject + Verb + Object

Câu tiếp diễn:  
Subject + be + Verb-ing + Object

Câu hoàn thành:  
Subject + have/has + Verb C3 + Object

Câu hoàn thành tiếp diễn:  
Subject + have/has + been + Verb-ing + Object



| Thì           | Câu đơn          | Câu tiếp diễn             | Câu hoàn thành         | Câu hoàn thành tiếp diễn        |
| ------------- | ---------------- | ------------------------- | ---------------------- | ------------------------------- |
| **Hiện tại**  | S + V(s/es) + O  | S + am/is/are + V-ing + O | S + have/has + P2 + O  | S + have/has + been + V-ing + O |
| **Quá khứ**   | S + V2 + O       | S + was/were + V-ing + O  | S + had + P2 + O       | S + had + been + V-ing + O      |
| **Tương lai** | S + will + V + O | S + will be + V-ing + O   | S + will have + P2 + O | S + will have been + V-ing + O  |

| Dạng câu / Thời gian | **Hiện tại**        | **Quá khứ**        | **Tương lai**            |
| -------------------- | ------------------- | ------------------ | ------------------------ |
| **Simple**           | I eat rice.         | I ate rice.        | I will eat rice.         |
| **Continuous**       | I am eating rice.   | I was eating rice. | I will be eating rice.   |
| **Perfect**          | I have eaten rice.  | I had eaten rice.  | I will have eaten rice.  |
| **Perfect Cont.**    | I have been eating. | I had been eating. | I will have been eating. |


Ở đây, động từ sẽ thay đổi theo thời gian:
Subject+was/were+object.

## 1. TRẠNG TỪ CHỈ TẦN SUẤT (Adverbs of Frequency)

### 📌 Chia theo % từ **luôn luôn** đến **không bao giờ**:

| Trạng từ      | Nghĩa tiếng Việt      | Tần suất ước chừng |
| ------------- | --------------------- | ------------------ |
| always        | luôn luôn             | 100%               |
| almost always | gần như luôn luôn     | 95%                |
| usually       | thường xuyên          | 80%–90%            |
| often         | thường                | 70%–80%            |
| frequently    | thường xuyên          | 60%–70%            |
| sometimes     | thỉnh thoảng          | 40%–60%            |
| occasionally  | đôi khi               | 30%                |
| seldom        | ít khi                | 10%–20%            |
| rarely        | hiếm khi              | 5%–10%             |
| hardly ever   | gần như không bao giờ | ~5%                |
| never         | không bao giờ         | 0%                 |

## 2. TRẠNG TỪ CHỈ MỨC ĐỘ (Adverbs of Degree)

### 📌 Dùng để nhấn mạnh, giảm nhẹ hoặc đánh giá mức độ của hành động/tính từ/trạng từ:

#### **Mạnh (Tăng cường)**
| Trạng từ   | Nghĩa tiếng Việt  |
| ---------- | ----------------- |
| extremely  | cực kỳ            |
| absolutely | hoàn toàn         |
| completely | hoàn toàn         |
| totally    | hoàn toàn         |
| very       | rất               |
| really     | thật sự           |
| so         | quá               |
| deeply     | sâu sắc           |
| terribly   | cực kỳ (tiêu cực) |
| too        | quá mức           |

#### **Trung bình / Nhẹ**
| Trạng từ | Nghĩa tiếng Việt |
| -------- | ---------------- |
| quite    | khá              |
| rather   | hơi, khá         |
| pretty   | tương đối        |
| fairly   | khá là           |
| a bit    | một chút         |
| slightly | hơi              |
| just     | chỉ              |

#### **Phủ định / Giảm nhẹ**
| Trạng từ | Nghĩa tiếng Việt |
| -------- | ---------------- |
| hardly   | hầu như không    |
| scarcely | gần như không    |
| barely   | chỉ vừa đủ       |

#### **Dùng với “enough”**
| Trạng từ | Nghĩa tiếng Việt |
| -------- | ---------------- |
| enough   | đủ               |
